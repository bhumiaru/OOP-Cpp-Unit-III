## Unit II – Inheritance

This repository contains the C++ programming activities for Unit II
of Object-Oriented Programming with C++.


## List of Programs

### Program 01 – Basic Single Inheritance
Demonstrates single inheritance using a base class and a derived class.

### Program 02 – Protected Member Access
Demonstrates how a derived class can access a protected member of a base class.

### Program 03 – Public versus Private Inheritance
Demonstrates the effect of public and private inheritance on accessibility.

### Program 04 – Multilevel Inheritance
Demonstrates multilevel inheritance using Person, Employee and Manager.

### Program 05 – Hierarchical Inheritance
Demonstrates hierarchical inheritance using Vehicle as a common base class.

### Program 06 – Multiple Inheritance
Demonstrates multiple inheritance using academic and sports records.

### Program 07 – Resolving Multiple-Inheritance Ambiguity
Demonstrates how ambiguity between base-class functions can be resolved.

### Program 08 – Constructor and Destructor Order
Demonstrates the order of constructor and destructor execution.

### Program 09 – Parameterized Base Constructor
Demonstrates initialization of a parameterized base class from a derived class.

### Program 10 – Function Overriding
Demonstrates function overriding using virtual and override.

### Program 11 – Abstract Class
Demonstrates an abstract class using a pure virtual function.

### Program 12 – Virtual Base Class and Diamond Inheritance
Demonstrates the use of a virtual base class to solve diamond inheritance ambiguity.

### Program 13 – Friend Class
Demonstrates access to private data using a friend class.

### Program 14 – Nested Class
Demonstrates the creation and use of a class inside another class.

### Program 15 – Mini-Project: Vehicle Rental System
Demonstrates an inheritance-based vehicle rental application.

### Program 16 – Mini-Project: Employee Payroll System
Demonstrates an employee salary system using an abstract class and derived classes.
